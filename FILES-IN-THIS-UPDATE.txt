WHAT CHANGED
  * Bills and chits -> Print again now goes straight to the thermal printer.
    It was the last button still opening the browser print dialog.
  * Administration -> Settings -> "Clear all data" is now called
    "Clear patients and billing", because that is what it does. See below.
  * Printer settings are per PC, and now say so on screen.

TWO COUNTER PCs, TWO PRINTERS
  Already works. Printer settings are keyed to the machine, not the account,
  so each PC keeps its own share path, username and password. Set MC1 up at
  MC1 and MC2 up at MC2.

  Keyed to the machine on purpose: the printer is plugged into a PC. If it
  followed the account, a cashier covering the other window would print onto
  the printer next to their colleague. Five assertions cover this now.

  A PC that has never been set up falls back to the counter-wide setting, so
  nothing that was already printing stops.

CLEARING THE TRIAL DATA
  Administration -> Settings -> Clear patients and billing.

  Removes: patients, visits, chits, bills, payments, lab orders and results,
  prescriptions, sales, stock movements, doctor earnings, and resets the
  numbering so the first real patient is number 1.

  Keeps: staff, doctors, departments, services and prices, products,
  suppliers, and every setting including the logo.

  Guarded by three locks: the admin.wipe permission, your own password typed
  again, and the hospital name typed exactly. It takes a backup first and
  refuses to proceed if the backup fails.
